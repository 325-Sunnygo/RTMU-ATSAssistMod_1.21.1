# RTMU-ATSAssistMod_1.21.1

Minecraft **1.21.1 / NeoForge** port of **ATSAssistMod** — ATS/ATC safety-device assist
(地上子・車上装置・速度照査) for RealTrainMod.

- **Original work**: ATSAssistMod by **Kaiz_JP** (`jp.kaiz.atsassistmod`)
- **License**: **GPL-3.0** — inherited from the original ATSAssistMod. See [`LICENSE`](LICENSE).
- **Runtime dependency**: [RealTrainModUnofficial (RTMU)](https://github.com/325-Sunnygo/RealTrainModUnofficial).
  Distributed as a separate jar and loaded alongside RTMU.

## Branches
- `1.21.1` — this branch: the Minecraft 1.21.1 NeoForge port.
- `master` — the original ATSAssistMod sources (unchanged).

## Build
This is a **subproject of RTMU** (`compileOnly rootProject`) and is built together with RTMU,
not standalone.
